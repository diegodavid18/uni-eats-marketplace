Guía de Configuración

1

Registrar Aplicación en Azure AD

Registra tu aplicación en Azure Active Directory para obtener las credenciales necesarias.

  1. Ve al Portal de Azure
  2. Navega a "Azure Active Directory" → "App registrations"
  3. Haz clic en "New registration"
  4. Completa el formulario y registra la aplicación
  5. Copia el "Application (client) ID" y "Directory (tenant) ID"
2

Crear Client Secret

Genera un secreto para que tu aplicación pueda autenticarse.

  1. En tu aplicación registrada, ve a "Certificates & secrets"
  2. Haz clic en "New client secret"
  3. Agrega una descripción y selecciona la duración
  4. Copia el valor del secreto (¡solo se muestra una vez!)
3

Configurar Permisos de Power BI

Otorga los permisos necesarios para acceder a Power BI.

  1. Ve a "API permissions" en tu aplicación
  2. Haz clic en "Add a permission"
  3. Selecciona "Power BI Service"
  4. Agrega permisos: "Dataset.Read.All", "Report.Read.All", "Workspace.Read.All"
  5. Haz clic en "Grant admin consent"
4

Configurar application.properties

Agrega las configuraciones en tu archivo de propiedades.

# Power BI Configuration
powerbi.client-id=tu-client-id-aqui
powerbi.client-secret=tu-client-secret-aqui
powerbi.tenant-id=tu-tenant-id-aqui
powerbi.workspace-id=tu-workspace-id-aqui
powerbi.report-id=tu-report-id-aqui

Probar Conexión

Una vez configurado, puedes probar la conexión con Power BI.
